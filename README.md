# ML Specialization

Репозиторий содержит проекты, выполненные в рамках углубленного курса по машинному обучению и компьютерному зрению. Работа охватывает путь от классических линейных моделей до современных архитектур глубокого обучения.

## 🏆 Ключевые проекты

### 1. Финальный проект: Deepfake Detection (Командная работа) (08_ML_team*.ipynb)

**Задача:** Создание системы бинарной классификации для отличия реальных лиц от сгенерированных нейросетями.
*   **Стек:** CNN, архитектуры уровня ResNet/EfficientNet, работа с несбалансированными данными.
*   **Результат:** Модель прошла проверку на лидерборде (f1_score = 0.98), реализован полный пайплайн обучения и оценки.
*   **Фокус:** Качество кода, воспроизводимость и командное взаимодействие.

### 2. Сравнительный анализ архитектур на MNIST & Fashion MNIST (6 ml)
Комплексное исследование влияния различных слоев на точность классификации:
*   **Эксперименты:** Сравнение полносвязных (Dense) сетей и сверточных (CNN).
*   **Оптимизация:** Использование Dropout, Batch Normalization и различных функций активации (ReLU, Leaky ReLU).
*   **Аугментация:** Применение трансформаций для повышения устойчивости модели.
*   **Архитектуры:** Реализация Skip-connections (аналог ResNet) для борьбы с затуханием градиента.
*   **Отчет:** Подробная таблица метрик (Accuracy, Precision, Recall, F1-score).

## 📚 Изученные темы и навыки

### 🟢 Основы и Классический ML
*   **Линейная алгебра:** Матричные вычисления, разложения, работа с векторами.
*   **Линейные модели:** Регрессия и классификация, регуляризация (L1/L2).
*   **Оптимизация:** Реализация и настройка градиентного спуска (SGD, Adam).

### 🔵 Deep Learning & Computer Vision
*   **Neural Networks:** Архитектура скрытых слоев, Backpropagation.
*   **CNN:** Сверточные слои, пулинг, современные CV-архитектуры.
*   **Text2Image:** Изучение основ диффузионных моделей и архитектур генерации изображений по тексту.
*   **Инструменты:** Jupyter Notebook, визуализация графиков обучения (loss/accuracy).
